口径说明：README 指向 TrackEval 和 MOTChallengeEvalKit_cv_test 中的 GT 及其
评估流程。本文三组结果是本次额外建立的对照口径：其中“工具标注”取自跨视角
评估包，不能替代 TrackEval 中指定的单视角 GT；JSON 全量结果也不是 README
指定的最终指标评估流程。下表不应作为严格遵循原作者评估流程的复现成绩。

评估已完成全部 22 个场景、44 个摄像头序列、58,038 张测试图像的推理。
使用第二阶段最终权重 `output/vision_local_stage2/model_final.pth`。
结果来源为 `output/vision_evaluation/metrics.json`；论文参考本地 PDF 正文表 2
的 VisionTrack / GMT 行。

## 如何解读

原始标注无冲突子集的 HOTA、IDF1、CVIDF1 分别比论文报告数值低 0.48、
0.72、0.07 个百分点。但其覆盖范围不同，不能据此认定完整测试集严格复现成功。

JSON 全量的跨视角身份指标 CVIDF1 为 80.81，与论文 81.30 接近；其 HOTA、
MOTA 等数值高于论文报告值，但不能直接宣称超越论文。

三个评估来源的 GT 框数量分别为 189,785（原始子集）、185,740（工具子集）和
564,980（JSON 全量），表明它们不是同一套评估样本。

## 尚未对齐的设置

- 原始与工具标注存在重复帧/ID 冲突，按已确认的策略排除完整场景，未改写标注。
- CVMA_TrackEval 保留仓库的交错视角时间轴，使用 TrackEval CLEAR；本机无
  MATLAB，未核对其与原 MATLAB 评估后端的逐项等价性。
- 论文正文描述每阶段 14,000 次迭代、batch size 8、Adam、学习率 5e-4；
  本次遵循仓库配置，每阶段 20,000 次，IMS_PER_BATCH 为 1，使用 AdamW，
  两阶段基础学习率分别为 5e-5 与 2e-5。视频 batch 与图像 batch 的含义也需区分。
- 推理保留了当前代码的随机框扰动、固定空间半径系数等实现，与论文描述存在差异。

目前可确认训练、全量推理及指定口径的指标计算均已完成。若需要严格论文复现，
应优先统一测试标注、场景范围和评估协议，再核对训练与推理设置；不宜仅根据
当前指标差值调整测试参数。
